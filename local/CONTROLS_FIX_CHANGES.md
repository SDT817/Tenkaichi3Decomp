# r11 控制设置修复（2026-10-28）

官方基线：v0.1.38.9 / `6a8d1429e6b71618107d945aeb10c56f1cd7cc1c`。
旧本地版本：`Tenkaichi3Decomp-WiiLocal-r8-CN7-ImmediateI`，基于官方 v0.1.38.7 / `52b675c3ee4ed90f4f0d8e94217867a52638cc15`。保留旧目录，按三个源码端点逐文件合并；保留已安装版的中文显示、Wii 控制和已接受的 I 呈现设置，不带入另一独立大厅试验版本。

本次控制修复仅修改六个运行时文件：

- `control_bindings.cpp/.h`：GRAVE 使用不会与 Dolphin 引号冲突的名称，默认绑定、输入列表和导入共用。补充可对应 SDL 扫描码的 Dolphin 特殊键别名。导入转换区分“不支持的输入”与“语法无效”。不修改原 Dolphin 解析器、求值顺序、输入采样和战斗算法。
- `control_editor.cpp`：检测物理按键时也使用同一个安全名称，列表选择与直接检测行为一致。
- `control_profiles.cpp/.h`：遇到不支持的 Dolphin 输入，只清空包含该输入的动作，继续导入其余动作，附带诊断。整条动作清空，避免删除未知运算数后改变 `J & !unknown` 等逻辑的含义。语法错误、损坏文件、非法数值继续报错。导入仍跟随当前分离开关。
- `control_profile_ui.cpp`：显示被留空的动作；移除“读取”，下拉选中预设即读取并应用。读取失败保留现用配置。

分享码改为 `BT3W2:`：原 UTF-8 预设 INI → zlib 压缩 → CRC32（压缩负载，4 字节小端）→ 无填充 Base64URL。复用 zlib，不重写压缩算法；旧 `BT3W1:` 仍可读取。新分享码需要此版本或支持 W2 的更新版，旧版不能读取 W2。解压限制为 1 MiB，并验证压缩流完整消费、CRC、表达式限制及格式。Windows 通过现有本地构建适配器静态链接工具链的 `libz.a`，不新增运行时 DLL，许可证附带。

官方升级的三个 UI 冲突：保留官方观战开关及连接状态条件；设置窗口同时保留本地 Wii 宽布局和官方大厅/观战入口。官方新的网络、匹配、大厅、观战和回滚代码原样带入；没有本地网络或协议修改，协议仍为官方的 5。独立编译官方六个网络对象并去除调试路径后逐字节比较。

`records/code-history` 保存本版本完整源码、旧本地源码、官方源码、官方→本版完整补丁、旧本地→本版增量补丁、逐文件补丁、文件哈希及三方合并记录。两个补丁在隔离目录实际应用后逐文件核对完整文件集合和内容；不是只有文字摘要。文本端点统一为 LF，原始官方 Git 源码压缩包另存。没有创建 Git 提交、推送或 PR。

构建：`python local/build_controls_fix.py`。常规检查使用 `python local/native_runner.py local/tests/run_profiles.py`、`run_profile_ui.py`、`run_editor.py`、`run_bindings.py`、`run_battle.py`、`run_parser_parity.py`、`run_navigation.py`；网络边界检查 `python local/tests/check_controls_fix_network.py`。真实 `1.ini` 按只读方式测试，测试文件路径可通过 `BT3_TEST_DOLPHIN` 替换。

## W3 分享码更新（2026-10-29）

仍基于上述官方 0.1.38.9。仅修改 `control_profiles.cpp` 和 `control_bindings.cpp/.h` 三个运行时文件：分享码改用 `BT3W3:` 固定顺序的 26 条表达式和非默认范围；保留模式、死区、震动。复用 Dolphin lexer 精简纯字母输入名的反引号及排版空白，导入后补运算符空格，例如 `J | F` 和 `N & ! SPACE`，保留键名内部空格、括号与运算顺序。文件格式和旧码 W1/W2 解码保持兼容，接收端分离设置规则不变。新码需支持 W3 的版本导入。
