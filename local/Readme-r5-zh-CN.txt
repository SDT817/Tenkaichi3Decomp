Wii 独立控制版 r5（官方 0.1.38.1，11059a6）

从 r4 合并官方更新：新版材质异步读取、渲染与音效修正沿用官方实现。

F1 → 控制 → Wii：所有预设读取、Dolphin 导入、手动导入、分享码导入都遵循当前“控制分离”开关，不再自动切换。
  组合 → 分离：左视角复制给上一个角色，右视角复制给下一个角色；暴血为左或右视角键，仍需双击。
  分离 → 组合：忽略独立的上一个角色、下一个角色、暴血，只使用左右视角。
只替换当前玩家正在使用的一套 Wii 表达式，另一套和 PS2 键位保持不变。
死区和震动继续沿用原有每玩家设置。保存/分享仍记录来源的分离状态，方便接收时转换；r4 分享码与预设可直接导入。

从 Dolphin 导入同时搜索：
  %APPDATA%\Dolphin Emulator\Config\Profiles\GCPad
  系统“文档”目录\Dolphin Emulator\Config\Profiles\GCPad
文档路径由系统获取，兼容 OneDrive/路径重定向。多份配置标注 AppData / 文档来源，同一目录去重。
找不到时提示手动导入。支持常见 Dolphin 键鼠和 XInput 混合表达式。
通用 DInput/SDL 原始手柄编号因设备排列不同，不能可靠对应时会提示重新绑定；不猜测转换。
校准/门限形状/Modifier/震动输出表达式不是移植版输入动作。

左右视角为不同的非空表达式时，合并暴血需要相同的输入范围；不同时明确提示先统一范围。
合并后超出原表达式上限会拒绝；导入失败不会部分改写当前键位。

Wii 游戏菜单、暂停与结算菜单改用移动左摇杆，十字键不再控制菜单移动。
菜单确认/返回仍为攻击键/飞行键（默认 Xbox X / A）。战斗、PS2 输入、双击算法不变。
F1 控制页继续只用键鼠操作界面，手柄可用于检测与按键测试。
F1 新增项、联机菜单、连接状态与联机统计补齐中文。服务返回的已知错误在显示层翻译，未知诊断保留原文。

更新包：退出游戏，解压覆盖现有游戏目录同名文件；按键设置、存档和解包资源保留。
完整包：按官方方式安装自己的游戏镜像；不附带镜像、解包数据或个人设置。
旧 r3 / r4 的 bt3_wii_controls.ini v2 直接兼容。

网络/协议代码保持官方 0.1.38.1 原样，协议仍为 5。
本机 PS2 / Wii 双实例联机已测试；r5 没有进行远程 UU 测试。

source.zip 保存完整源码。records.zip 的 code-history 保存：
  相对官方 0.1.38.1 的完整补丁、r4 → r5 增量补丁、逐文件补丁；
  官方及原样 r4 源码基线、逐文件哈希、合并与验证记录。
两份补丁均实际应用并逐文件核对可恢复。旧包保留；没有创建提交、推送或更新 PR。
