## r3 修复的精确代码差异

`control_editor.cpp::append()` 仅修改插入起止位置的两行：当 `sStart == sEnd` 时，两端都取 `sCursor`；有真实选区时仍取选区 min / max。ImGui 的 stb_textedit 在输入后可能保留旧的空选区锚点，旧实现误把该锚点当成光标，导致 `W &!` 后插 Z 变成 `W Z&!`。修复后为 `W &!Z`，继续插入仍正确。没有修改 Dolphin 表达式运算、优先级或战斗输入算法。

`local/tests/test_editor.cpp` 新增真实 `AddInputCharactersUTF8()` 用例：确认 cursor 已移至末尾、空选区锚点落后，再点选输入，校验两轮 `&!Z` 插入。已有选区替换测试保留。`run_bindings.py` 改用仍存在的官方游戏目录查找 SDL3.dll，避免失效路径；游戏发布包继续携带官方 SDL DLL。
