怎么核对、如何保存

1. 默认显示自定义字码。左右字形代表的字相同就选“正确”；不相同就输入应有的字。看不清可标记“存疑”，打开“放大 / 看例句”辅助判断。

2. 支持按现有字、修改后的字、字码和例句搜索。编码是稳定编号：例如 E2C2=您。重复映射只提示优先检查，并不自动判定错误。

3. 点击“导出修改表”，把下载的 JSON 文件发回，即可批量修正。长时间核对请同时“保存全部进度”；下次点“读取进度”继续。浏览器本地缓存只是辅助，文件导出才是可靠备份。

自定义字码左侧直接取自汉化 ISO 原字库，右侧为当前游戏 C 字体渲染器的实际 4×输出。其他字形左侧是已加载的点阵后备或未修改的美版字形，并非原 ISO 对照。空格及原有符号也保留在清单中。核对字库能修复同一码在全游戏的错字，不能替代翻译措辞校对；贴图上画死的字不属于此表。
