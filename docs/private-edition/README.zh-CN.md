# 0.17 私人版协作说明

这是当前已安装的 **0.17 / r22** 的完整代码，官方基线为 **0.1.39.1**，
提交为 `7b43a75bd8b0aeabcce0a22c45e1ad66162ac9d7`。
本次只整理并公开源码，不升级游戏，也不改动任何运行逻辑。

## 从这里开始

```powershell
git clone --branch codex/private-0.17 https://github.com/SDT817/Tenkaichi3Decomp.git
cd Tenkaichi3Decomp
python -X utf8 development/verify_recorded_source.py
git switch -c your-name/your-change
```

主整合分支为 `codex/private-0.17`。六条功能协作分支都从同一个完整版本开始：

| 分支 | 负责范围 |
| --- | --- |
| `codex/dev-wii-controls` | Wii 控制、逻辑按键、预设和独立设置 |
| `codex/dev-chinese` | 汉化、字库、术语和资源生成工具 |
| `codex/dev-performance` | 已验收的 I 版、Immediate、字库及菜单缓存 |
| `codex/dev-dragon-dash` | 首次龙冲方形花屏修复 |
| `codex/dev-lobby` | 大厅、服务器目录、中继接入、更新和启动器 |
| `codex/dev-trunks-test4` | 特兰克斯（格斗）测试4的四帧飞行调整 |

这些分支包含全部功能，方便不同开发者在各自的工作线上继续修改。
它们不是六个能够独立套用到官方版的补丁；UI、输入和渲染存在共享文件。
后续合并请求请以这个仓库的 `codex/private-0.17` 为目标。
需要直接推送的人，由仓库管理员邀请为协作者；其他人可以先 fork 再提交 PR。

## 代码与修改记录

[功能文件说明](FEATURES.md) 列出每部分的入口和边界。
[构建说明](BUILDING.md) 区分完整构建、旧增量构建和本地资源维护工具。
`local/` 内保留历次修改说明、测试源码与构建适配；
`development/provenance/` 内保存已验收源码逐文件 SHA-256 和已有验证记录。
历史记录中的“不提交”“不推送”描述当时的工作状态；本次已授权公开代码。

`development/analysis-tools/` 补入此前保存在分析目录里的汉化维护脚本，
保留其原有代码及同目录 Python 依赖。它们仍引用历史资源目录或本机路径，
属于维护工具，不是下载后可以直接运行的一键安装程序。

## 跟随官方更新

先在新分支合并新的官方提交，再处理本地功能的冲突。
不要拿旧完整文件覆盖新版官方文件，也不要同时把协议号当作私人版本号修改。
当前协议 6 来自官方基线；0.17 是私人发行版本。
控制、暂停、回滚、输入帧、字库缓存和大厅传输涉及的改动分别核对并测试。
历史测试里的“网络与官方一致”只对相应历史版本成立，不能当作当前整合版声明。

本仓库不含 ISO、解包资源、修改过的游戏资源包、个人存档、管理员身份文件、
服务器数据库或发布私钥。汉化运行代码已包含；完整汉化效果仍需另行取得匹配的
已验收汉化资源和合法自备游戏资源。已部署更新器的签名私钥仍由发行者保管。
开发游戏本体时请直接运行自己构建的 EXE；现有正式启动器的文件校验可能把
修改后的发行文件恢复为正式 0.17，勿把正式安装目录作为开发输出目录。
